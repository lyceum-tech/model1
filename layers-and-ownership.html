FULL LIFECYCLE CONTROL
Lyceum controls provision, power, firmware, repair and sanitization. NICo is a candidate below Atlas. Hardware supplies a qualified base image.
HOST ACCESS ONLY
The provider controls physical lifecycle. Lyceum configures only what access permits. Atlas/Hydra can use the host; NICo cannot supply missing permissions.
